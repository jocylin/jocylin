澳门 200 亿政府引导基金 — IOSG 参与分析报告

TL;DR

澳门特区政府于 2026 年 2 月 27 日正式宣布筹建 200 亿澳门元（≈25 亿美元）首支政府引导基金，采用 "政府引导基金 — 母基金 — 子基金"三层架构，力争 2026 年内完成基金设立。

IOSG 的潜在参与点 不是被投项目，而是作为第三层的子基金 GP 或顾问角色。

核心结论：

  • 目前阶段最直接的接入点不是政府，而是对应方向的母基金 GP（中金资本、深创投等候选）
  • 现在还在政策宣告后、机构搭建前的窗口期，影响规则比按规则投标更有价值
  • 轻模式（顾问/SMA）/ Co-GP/ 独立子基金 GP 都是值得考虑的模式

第一部分：引导基金是什么 + 需要满足哪些条件

         ├─ 政府资本 LP（110 亿）
         ├─ 首批社会资本 LP（90 亿）
         └─ 政府管理实体 GP
              ↓ LP 出资

              ↓ LP 出资

         ├─ 母基金 LP
         ├─ 社会资本 LP
         └─ 市场化遴选的子基金 GP

1.5 投后绩效考核机制（非纯财务 LP）

这不是一支只看 IRR 的财务 LP。考核维度：

  • 政策引导：社会资本参与程度、重点产业和地域的投资占比
  • 社会效益：优质企业落户澳门/合作区数量、新增专利和技术、对澳门居民就业的支持、增加税收
  • 财务效益：基本收益率、分配收益倍数
  • 管理效率：资金使用效率、投放比率、投资合规性、制度建设

关键机制：管理费和业绩报酬将与基金的整体绩效评价结果挂钩 —— 不达标会被扣管理费/carry。

这些是母基金层级的竞争者。IOSG 尽量不与他们正面竞争母基金 GP 资格——IOSG 抢的是子基金那一层、且是他们都不懂的细分赛道（Web3 + AI infra + RISC-V）。

第二部分：IOSG 可选的参与方式 / 产品形态

下面列出 4 种 option。前 3 种（A/B/C）都在子基金层，按主动性 + 资源投入从轻到重排序，是 IOSG 主推的方向；Option D 在母基金层，是一个不同性质的选择，仅作备选。

Option A：纯顾问 / Sub-Advisor 模式

结构：IOSG 不做独立基金主体，作为某只母基金或子基金的专业顾问 / sub-advisor，提供 Web3/AI/RISC-V 赛道的投资建议、deal sourcing 和投后管理服务。

关键数字：

  • 没有自己的基金
  • 投顾服务费 + 项目分成（约 1% 顾问费 + 10% 项目 carry）
  • 不需要本地实体 / 牌照
  • 实际管理资金规模：不限，但 IOSG 没有控制权

和谁对接：母基金 GP（中金资本、深创投或横琴本地玩家），或直接对接子基金 GP 作为他们的赛道顾问

Option B：Co-GP 模式（与持牌本地伙伴合作）

结构：IOSG 与一家已持 AMCM 牌照的本地资管机构联合做子基金 GP。本地伙伴提供牌照 + 合规 + 政府关系，IOSG 提供赛道认知 + deal flow + portfolio 资源。Carry 和管理费按贡献分成（典型 50:50 或 60:40 偏 IOSG）。

关键数字：

  • 子基金规模建议：5–10 亿 MOP
  • 母基金 LP 出资比例 （比例未定，这个比例是参考内地政府的引导基金一般规定写的）：预期 30–40%
  • IOSG（联合本地伙伴）需自筹社会资本：60–70%
  • 牌照路径：借用本地伙伴的 AMCM 牌照（6–12 个月可启动）

和谁对接：

  • AMCM 持牌机构 list 里的中资银行系澳门资管（首选）
  • 本地家办 / 多家办（次选）
  • 澳门科技大学 / 澳门大学产业基金（产学研背书）

Option C：独立子基金 GP 模式

结构：IOSG 自申 AMCM 牌照（或横琴简化通道），设澳门本地子公司，募集独立的 "IOSG 大湾区科技子基金"。完整的 GP 主体，IOSG 拿全部 carry 和管理费。可作为一次性项目，也可作为长期 RMB/MOP 产品线的起点。

关键数字：

  • 子基金规模建议：2 亿 MOP（试水款）或 5–10 亿 MOP（标准款）
  • 母基金 LP 出资比例：争取 30–50%
  • IOSG 需自筹社会资本：50–70%
  • 牌照路径：自申 AMCM 牌照（12–18 个月）或走横琴简化通道（深合区私募基金管理公司转申澳门牌照，6–12 个月）
  • 本地团队：2–3 人 in 澳门 + 1–2 人 in 横琴
  • 主题包装："Web3 Infra × AI × 开源芯片 IP（RISC-V）× DePIN"
  • LP 来源：政府引导基金 anchor（30–50%）+ 澳门家办、横琴产业资本、大湾区上市公司战投部、中资保险（社会资本配套）

两种走法（同一个 Option 内的选择）：

  • C-1 一次性子基金：先把第一支 2–10 亿 MOP 子基金跑通，验证商业模式和政府关系，跑完再决定是否继续
  • C-2 战略级 RMB/MOP 产品线：把第一支子基金作为长期产品线的起点，承诺持续募集第二、三期，与现有 USD flagship 基金做 deal-level 联合投资协议——这个版本投入更大（澳门 + 横琴双 office、5–8 人本地团队、独立 IC、独立 LPA），但战略意义最大

和谁对接：直接对接母基金 GP（中金资本、深创投是优先级最高的两家），同时跟政府筹建工作组（经济财政司司长办公室 + AMCM + 经科局 + 招商投资促进局）保持信息同步

和谁对接：直接对接母基金 GP（中金资本、深创投是优先级最高的两家），同时跟政府筹建工作组（经济财政司司长办公室 + AMCM + 经科局 + 招商投资促进局）保持信息同步

Option D：IOSG 直接做母基金 GP

结构：IOSG 跳过子基金那一层，直接竞争母基金 GP 的资格——也就是政府引导基金底下的某只母基金（数字科技/集成电路方向那只），由 IOSG 主导或联合主导。IOSG 不直接投项目，而是作为母基金 GP 把钱再配置给若干只子基金（可能含 IOSG 自己的 specialist 子基金 + 其他 GP 的子基金）。

关键数字：

  • 母基金规模：10–30 亿 MOP（≈1.2–3.7 亿 USD，比 Option C 大 2–3 倍）
  • 政府引导基金 LP 出资比例：预期 30–50%
  • IOSG 需自筹社会资本：50–70%（绝对额比 Option C 大很多）
  • 商业模式：母基金 GP 的标准 carry 比直投基金薄（通常 0.5–1% 管理费 + 5–10% carry，因为收益主要来自下层子基金的 carry 再扒一层）
  • 牌照要求：更严格——大多数政府引导基金的母基金 GP 要求头部金融机构资质 + 大规模 AUM track record + 多赛道配置能力
  • 本地团队：要求显著高于子基金（10+ 人本地团队 + 完整中后台）
  • 主要工作：选 GP + 资产配置 + LP 关系管理（不是 IOSG 现有的强项）

核心障碍 — 为什么实际不太可行：

  • 能力不匹配：IOSG 的强项是赛道认知 + deal sourcing（直投能力），不是 fund-of-funds 的 GP 选择和资产配置
  • 竞争对手太强：母基金 GP 这一层的竞争者是中金资本、深创投、高瓴、横琴金投——他们有 IOSG 缺的：大规模 AUM、国资背景、大湾区落地经验
  • 政策考核不利：政府考核母基金 GP 看的是"整体大湾区产业落地 + 社会资本撬动 + 多赛道覆盖"——这对单一赛道 specialist 的 IOSG 是反向选择
  • 经济账不划算：30 亿 MOP 母基金每年管理费收入约 1500–3000 万 MOP（≈200–400 万 USD），相比 10 倍工作量 ROI 远不如做子基金

和谁对接：政府筹建工作组（高层）+ AMCM + 财政司 + 可能的联合主导方（如某家中资银行系澳门资管、某家大湾区国资）

适用情境：仅当出现极特殊机会窗口时考虑——例如政府主动邀请、有大湾区国资央企愿意做 co-GP 联合主导（IOSG 提供赛道认知，对方提供资金体量和政府关系）

综合推荐

Two-step 推荐路径：

  1. 先以 Option A 入场：成本极低、可逆，3–6 个月内验证商业可行性、政府关系强度、母基金 GP 兴趣度
  1. 基于 A 的反馈，决定下一步：
    • 反馈正面 + 资源到位 → 升级到 Option C（一次性 C-1 或战略级 C-2）
    • 反馈中性 → 停留在 Option A 或微升到 Option B
    • 反馈负面 → 撤出，几乎无沉没成本

Option D 的位置：作为"如果政府主动找上门 / 有央企愿意联合主导"的备选 path，不作为主动追求的目标。

不推荐路径：

  • 直接主动追求 Option D：能力不匹配、概率太低、ROI 不划算
  • 跳过 Option A 直接到 Option C：失去试水机会，遇到不可预见问题时调整空间小

第四部分：执行路径（公司层面）

阶段 1：侦察与建立存在感（现在 — 2026 Q3，约 3 个月）

阶段 1 的所有动作都围绕两个核心目的展开。

核心目的 1：让澳门政府决策圈知道 IOSG 是谁、能提供什么

解决的问题：现在澳门政府决策圈对 IOSG 完全陆生，等法规出台后再出现 = 没有任何位置。需要在 2026 Q3–Q4 法规定稿前，让决策圈记住 IOSG = "Web3 + AI infra + RISC-V 赛道的 specialist"。

动作 1.1：通过学术机构做"软性引荐人"进入政府视野

a) 做什么

以"产业资本与学术研究机构探讨 web3/AI/开源芯片产业转化合作"为名义，同时接触 3–5 家澳门学术机构。重点不是真的要做产学研合作，是让学术机构成为 IOSG 接触政府的"软性引荐人"——冷启动接触政府会被定位为"又一家要钱的 GP"，但从学术机构手里转介进去会被定位为"带着产业资源的合作伙伴"。

b) 找哪些机构

优先级 1（三家同时接触，以应不同机构反应速度不一）：

  • 澳门大学 · 智慧城市物联网国家重点实验室。主任是澳大校长宋永华本人（澳门学术圈话语权最高者），副主任马少丹是主要对接人。研究方向含智能传感、城市大数据、智慧能源——是 DePIN 赛道的传统行业版本，narrative 最好接
  • 澳门大学 · 模拟与混合信号集成电路国家重点实验室 · AMSV-IG 工业盟友计划。这家已有标准化的产业对接通道 AMSV-IG，IOSG 可直接申请加入工业盟友，比走一般合作路径快很多。创始人马许愿（Rui Martins）是 IEEE Fellow、澳门微电子奥基业人。对应 RISC-V/zkVM/开源芯片 IP narrative
  • 珠海澳大科技研究院（ZUMRI）。澳大在横琴的官方科技转化主体，已设 8 个研发中心（含智慧城市研发中心、微电子研发中心），与合作区 10+ 企业有联合研发关系。院长陈臻。"澳门研发 + 横琴转化"是政府引导基金明文要求的产业落地模式，ZUMRI 是现成 plug-in 点

优先级 2（优先级 1 冷场时启动）：

  • 澳门大学 · 计算机与信息科学系。与广东省智能科学与技术研究院有联合培养项目，做 AI、类脑计算。IOSG 主推 AI agent 赛道时的学术口
  • 澳门城市大学 · 数据科学学院。是澳门唯一明确把区块链列为研究方向的学院，同时是横琴博士后科研工作站伙伴基地。作为"遇到对区块链最不陆生的学术机构"的备选

优先级 3（最后备选）：

  • 澳门科技大学 · 计算机科学与工程学院：CS 学科世界 101–125 区间，跟政府关系也很紧
  • 珠海澳科大科技研究院：澳科在横琴的对应机构，比 ZUMRI 晚

c) 最终好处与目的

  • 学术机构主动把 IOSG 介绍给政府对接的产业部门（比 IOSG 冷启动 reach 转化率高 5–10 倍）
  • 收到的信号是 "IOSG 是带着产业资源进来的合作伙伴" 而不是 "又一家 GP"
  • 同时获得产学研背书，为后续子基金申报加分
  • ZUMRI 这条线额外解决了 IOSG 未来在横琴落地的现成通道
