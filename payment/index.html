01

为什么是现在

三股相互独立的变化，打开了一个 18 个月前还不存在的窗口。

监管

一个已经生效的监管闭环

香港稳定币条例已于 2025 年 8 月生效，LEAP 框架现已端到端覆盖稳定币、虚拟资产交易与代币化 RWA。初期预计只发放数张牌照——能走到队伍前列的，靠的是协调能力，而不只是规模。

市场

一个交易高峰

加密支付公司在发卡、跨境 PSP、代币化通道等方向以创纪录的估值融资与退出。这个赛道有势能、有资本、有真实收入——但在亚洲还没有一个共享的、中立的归属地。

结构

一个组织者真空

跨境结算领域最有公信力的中立组织者已经退场，多边的中间地带空了出来。机会属于一个私营组织、合规优先的商业通道——而不是又一个单一阵营的平台。

机会所在

今天，这些公司里没有一家身处一个多边的、中立的、由亚洲组织的联盟之中。这正是这个 network 要去占据的位置。

02

这个 network 做什么

四项功能，每一项都让成员从第一个季度起就能用上——它不是一场会议，也不是一个没有通道的标准机构。

Function 01

组织

由创始成员组成、每季度召开的闭门 working group，外加一年一度的香港峰会。一个真正让搭建亚洲支付通道的人共同制定议程的房间。

Function 02

互联

成员之间互相打通——发卡对接跨境通道，代币化资产经由稳定币通道结算，合规工具在 PSP 之间共享。Network 充当撮合方。

Function 03

代表

在与香港监管机构和政策部门的对话中，提供一个统一的集体声音。就框架与用例清晰度进行沟通，作为一个群体，远比一家家单打独斗更便宜、也更可信。

Function 04

研究

一份季度亚洲支付研究报告，以及一份持续维护的成员名录——共享的市场情报，抬高每一位参与者的站位。

03

设计原则

联盟如何在结构上保持中立、并值得加入。以下是创始阶段的设计承诺——与创始成员共同打磨，而非既定条款。

P1

与贡献挂钩的经济结构

联盟的设计目标是：在共享结算层产生的经济价值，按对 network 的贡献进行分配，而不是被单一发行方独占。其意图是成员之间的结构性利益对齐；具体机制与创始成员共同制定。

P2

非歧视性定价

成员在定价上一视同仁，不论规模大小，沿用成熟清算机构的合作社模型。没有成员能仅凭体量大就买到优势。

P3

辖区中立的治理

董事会的设计确保没有任何单一辖区能够主导。中立性本身就是资产；联盟刻意不被搭建成任何一方阵营的工具。

P4

合规优先、chain-agnostic

从一开始就内置合规姿态与准入控制，且不绑定任何单一公链或发行方。真实的资产与真实的通道，而不是一堆 logo 的集合。

04

创始合作伙伴得到什么、付出什么

作为创始合作伙伴，你将

  • 参与书写治理规则——董事会结构、准入规则与经济设计由创始成员共同确定，而非自上而下下发。
  • 坐在季度 working group 中，并参与塑造年度峰会议程。
  • 获得成员间互联——与其他 anchor 的暖性引荐与技术对接。
  • 作为一个被认可的群体的一员，加入香港的集体监管对话。
  • 在 network 的研究与对外形象中获得创始成员身份的认可。

作为回报，我们希望伙伴

  • 指派一位具名的资深代表进入 working group。
  • 在有商业意义之处，就互联与其他成员真诚合作。
  • 遵守联盟的合规与准入标准。
  • 在头两个季度协助打磨创始章程。
关于发起方

Asia Payment Network 由 IOSG Ventures 发起。IOSG 是一家自 2017 年起活跃于数字资产与支付基础设施领域的投资机构。

IOSG 的角色被刻意限定：组织、研究，以及投资关键公司的股权。联盟由成员塑造，IOSG 自身不持牌、也不经营任何支付业务。目标是让这个 network 的生命力超越、并成长得超过任何单一组织者。

创始成员的规模，是刻意做小的。

我们把第一批成员控制在 6 到 10 家 anchor，以保证治理可运作、每一个创始声音都有分量。如果你的公司在亚洲、或面向亚洲搭建支付、结算或代币化通道，我们想和你聊聊。
