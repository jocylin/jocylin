Prompt 的本质：极致压缩

📖
一本 314 页的书可能只讲一个词
《定位》讲的就是"占领心智"。作者把整本书压缩进一个词。
💎
压缩即解压的密钥
跟 Claude 说"尼采的生命意志"，它就能展开整本书。你说准那个词，AI 就能完成解压。
🧬
Read in, Prompt out
你脑子里的知识决定你 Prompt 的上限。框架只是辅助轮——拆掉它，才能飞。
› 真正重要的不是用什么语言写 Prompt，而是被极致压缩的那几个词。那几个词才是核心。

两个压舱石

⚓

1. 什么是不变的？

2. 稀缺性转移到哪了？

体力稀缺 → 脑力稀缺 → 心力稀缺

注意力稀缺 → 信任稀缺

追着稀缺性走，永远不会错。

› 看一个项目，问它解决的是哪种稀缺性。互联网投平台（马太效应），AI 时代投垂直深井（长尾效应）。
