Morphic — LP Investment Brief (6-10-2026)

本件为 LP / 联合投资人向资料。所有 traction / 融资 / 客户数据均为创始人 2026-06-10 通话中自报（per founder），未经独立审计验证。实体：Morphic（morphic.io，美国新设主体）。
交易背景：Morphic 是创始人 Joshua Sum（Josh S）于 2026 年在美国新注册的公司，与其早期 OnePiece Labs 加速器项目 "Socrates"（agent swarm 基础设施）为不同法实体——旧主体将做 mutual cancellation 关闭，以保持股权干净。本轮为 Morphic 的首轮融资。截至 2026-06-10：已 committed 约 $225K；所有 SAFE 统一以 $35M post-money cap 签署。融资结构两种路径（由 lead 决定）：(1) 先募 $2M pre-seed，约 3 个月后再开 seed；(2) 若有强势硛谷 lead 愿意吃下整轮，则一次性完成一个更大 round，随后 6–8 个月不再融资、专注 GTM。估值交由 lead / 市场定价。本 deal 由 Yiping 引荐（Yiping 与创始人已相识）。创始人 2026-06-10 在 Singapore（停留至周五上午，参加 Super AI 大会）。
推荐：推荐希望增加 AI 应用层 / agentic 企业软件 exposure 的投资人。Morphic 并不是又一个 AI CRM，而是在做"AI 时代的 company brain / 自适应 agentic workspace"——把 task 管理、wiki、CRM、data tables 与跨四者的 agent 统一在一个平台，主张"在我们成功的世界里没人再需要单独的 CRM"。相比 Day AI / Attio 这类单点 AI CRM，Morphic 同时具备统一数据底座、temporal context graph（非简单 RAG，号称 90% 长会话检索准确率，per founder）、BYO-agent 多人多智能体协作，长期估值锰点更接近 Notion / 企业 OS 而非单一 CRM。
Upside 视角：公司成立 2 个月、开售 1 个月即做到约 $100K ARR / 30 客户（per founder），并已搭好分发飞轮（创始人运营 SF 头部 AI 大会 + Plaud / GMI Cloud 等渠道分成）。当前 $35M post 的入场价位，对一个已有真实付费、且具备 token 批发折扣（15–25% margin，per founder）与数据销售双重经济模式的极早期项目，若 12 个月内兼现其 $10M ARR 目标并以 AI 企业软件倍数定价，存在显著 upside；下行风险在于单一创始人、2 个月历史、指标均为创始人自报且未经审计（见风险）。

产品介绍

  • 定位：自适应、自装配的 agentic workspace——让任何人（不只是开发者）能构建自己的"company brain"。对标用 Notion / Airtable + n8n / Zapier 拼接出企业大脑的痛点，用单一平台统一控制。
  • 四大原生原语（primitives）：task 管理、wiki / 文档、CRM、data tables（自定义对象 + 字段）——这些是用户拥有的数据底座；上层的智能层决定何时插入记录、解析、调用工具。“我们不是 CRM，但能在 5–10 分钟内为你搭出一个 CRM。”
  • BYO-agent + 多人多智能体协作：平台内一键部署 OpenClaw / Hermes 等外部 agent，让人与不同 agent 在同一 multiplayer 环境协作；模型不可知（任意 LLM）。区别于 Cowork / Codex 这类只包装 workflow 的产品：Morphic 更深——同时存储数据、做组织与 context ingestion。
  • 技术护城（per founder）：以 temporal context graph（随使用动态调整节点 / 边、跟踪状态随时间变化）取代简单 RAG；self-improving harness（compacting window / 长短期记忆 / system prompt 自调）；以任务完成信号做类 gradient-descent 的检索优化。号称长会话检索准确率达 90%。
  • 客群：以 B2B 为主，亦可 prosumer（类 Notion 双面）。

我们的押注

  1. 赛道升维：从单点 AI CRM 到“company brain”企业 OS — a16z（2026-05）提出 CRM 正被上层“智能层”架空，switching cost 迁向 workflow / context。Morphic 一开始就做统一 workspace + temporal context graph，押注“智能层 + 数据底座”一体，估值锰点朝企业 OS 而非单一 CRM。
  1. 双经济护城：data moat + token margin — 以 temporal context graph（难迁移）+ tribal knowledge 个性化为数据/切换护城；以 token 批发折扣 + 数据销售 + 90% 收入返还构造用户锁定与成本优势。若飞轮转起，后发者难追（均 per founder，待验证）。
  1. 分发是真正的创始人套利 — 创始人运营 SF 头部 AI 大会 + 多家品牌渠道分成，是同阶段对手没有的冷启动氠气优势；1 个月 $100K ARR 是该氠气的初步验证。
  1. 极早期 + 加密可扩展面 — $35M post 入场远低于头部对手；项目有 crypto-native 起源（Telegram 迁移 / 加密客群），是 IOSG 可加值且 LP 可取得差异化 exposure 的点。

风险

  • 单一创始人 + 公司仅 2 个月：无联创（仅在洽谈），执行风险集中于一人；公司历史极短，无法用时间验证留存与 Scale。
  • 所有指标为创始人自报、未审计：$100K ARR、30 客户、90% 检索准确率、token margin、Plaud $300M 等均需尽调验证；建议 LP 要求看 client logo / 合同 / 后台数据。
  • 赛道拥挤、对手资金碾压：Day AI、Attio、Rox、Reevo 资本与分发占优；同时 Notion / Airtable 等 workspace 在位者正装 AI。Morphic 需证明“更宽平台”不会变成“样样都做、样样不深”。
  • 战线过宽 / 执行难度：同时做 workspace + CRM + agent + GTM 代理 pod + 数据销售，对 6 人团队是极高执行要求；GTM“去响”依赖一次性流量爆发，可持续性存疑。
  • 主体切换：旧 Socrates 主体尚需 mutual cancellation；LP 应确认 IP / 用户 / 品牌已干净转入 Morphic 新主体。
