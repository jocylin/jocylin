Fireworks AI — 项目介绍 6-3-2026

交易背景
IOSG 近期拿到了 Fireworks AI 本轮（Series D 性质）的投资额度。本轮由 Index Ventures 领投 @ $15B post money，NVIDIA 等战略方跟投。意向确认窗口在 6 月中旬之前，上 cap table 概率较高。
如您对该机会感兴趣，IOSG 可安排直接参与。参与结构与费率：管理费 + carry，或一次性 transaction fee（按 size 商定）——具体数字待定，以最终确认为准。

Fireworks 是企业 AI 推理云的行业第一，团队来自 PyTorch，具有深厚的工程背景。AI 头部公司例如 Cursor、Genspark、Uber、DoorDash、Notion 都是 Fireworks 的客户。在推理性能、延迟、价格上 Fireworks 都具有明显优势，这极大提升了其 margin——尤其在 GPU 紧缺的当下，Fireworks 有能力 scale 得更快，用同样数量的 GPU 服务更多客户。过去一年里 Fireworks YoY 3x，达到 ~315M ARR，服务 10K+ 企业客户。

适合人群：该机会适合希望增加 AI、GPU Compute、Inference Layer 与开源模型生态 Exposure 的投资人。Fireworks 是目前少数同时具备超高速增长、顶级系统工程能力与明确单位经济优势的 AI Infra 公司之一，定位上接近「AI 时代的推理层 AWS」。对于看好 Agent、Copilot、企业 AI 化与推理需求长期爆发的投资组合而言，Fireworks 提供了较强的结构性 Beta 与平台级成长空间。

投资逻辑（核心看点）

Fireworks 对标 AI 时代的 AWS，把复杂的 Infra 抽象化。根据 Openrouter 的数据，推理需求正在以约 4x 的速度持续增长；若该趋势延续，Fireworks 有望在三年内做到约 $10B 的 Revenue（作为参照，AWS 2026 的 ARR 大概是 $150B）。

1. 推理是 AI 时代的「计算入口」，Fireworks 正占据 AI 应用层的核心流量节点

AI 正从「模型时代」进入「推理时代」。Agent、Coding Copilot、Search、Workflow Automation 等新应用形态正在持续推高推理需求，而行业同时面临 GPU 紧缺与推理成本高企的问题。对于 AI 应用而言，推理速度、稳定性与成本已经成为核心竞争力。

Fireworks 在这一轮竞争中已经建立起明显领先的位置。其核心优势并不仅仅是「更快」，而是能够在同样 GPU 资源下输出更多 tokens/sec，从而同时提升客户体验与平台毛利。对于 Agent Apps 而言，这意味着：

  • 更低的 inference 成本
  • 更高的响应速度
  • 更强的并发能力

而对于 Fireworks 自身，则意味着在 GPU 稀缺周期中，可以用同样的 H200 服务更多客户，从而持续扩大收入规模与市场份额。

本质上，Fireworks 已经站在 AI 应用收入链路的「咽喉位置」。其 Token 使用量已接近 Gemini 级别，每多一个 Cursor、Perplexity、Notion AI 这样的爆款应用，都会持续转化为 Fireworks 的收入增长。

当市场普遍预期 inference market 在未来 5 年达到 $100B+ 规模时，Fireworks 是极少数同时具备以下能力的推理平台：

  • 企业级客户能力
  • 开发者生态渗透
  • 顶级推理性能
  • 硬件生态合作位置

2. 推理服务最终会持续集中，而 Fireworks 拥有最强的单位经济与毛利护城河

从基础设施与 Fintech 领域的历史规律看，同质化基础服务最终都会走向集中。决定最终胜出的核心，并不只是增长速度，而是：

  • 更高的毛利结构
  • 更强的价格战承受能力
  • 更丰富的增值服务能力
  • 对客户工作负载更深的理解

Fireworks 在这些维度上都具备明显优势。其独有的推理优化能力，使其在价格略低于同行、性能明显领先的情况下，依然维持健康毛利。本质上，「同样 GPU 跑出更多 Tokens」直接等同于更强单位经济。当行业进入价格竞争阶段时，大量缺乏优化能力的平台会被持续压缩利润，而 Fireworks 反而可能成为少数仍能保持盈利能力的推理供应商。

与此同时，Fireworks 并不只是单一推理 API 生意。它正在形成完整产品闭环：推理服务、模型微调、多 LoRA 服务、企业部署、模型管理。当推理价格战真正开始后，微调与企业级服务将成为 Fireworks 对现有客户的重要增值路径，从而进一步提升客单价与客户留存。

Fireworks 的核心壁垒并不是销售网络，而是底层系统能力。PyTorch 创始团队带来的 CUDA、分布式系统、推理调度与 Kernel 优化能力，构成了极难复制的技术护城河。无论是 Together 的研究路线、Baseten 的企业平台路线，还是 Modal 的通用 Serverless 路线，都很难在未来 3-5 年内追平 Fireworks 在推理效率上的差距。FireAttention V4、推测解码、多 LoRA 服务等能力，是其系统工程优势的商业化体现。

3. 开源模型走向主流，而 Fireworks 是最大的结构性受益者之一

过去 12 个月，开源模型生态发生了根本性变化。Llama、DeepSeek、Qwen、Kimi K2 等模型，已经在多个 Benchmark 与真实场景中，对 GPT 与 Claude 形成可竞争位置。

与此同时，越来越多企业开始意识到：不希望被单一闭源 API 锁定、希望掌握数据主权、希望降低模型成本、希望拥有更强可定制能力。这意味着 AI 行业正在从「单一闭源 API 调用」，逐渐转向多模型 + 开源 + 可定制化推理，而 Fireworks 恰好位于这一范式迁移的核心位置。

Fireworks 的「BYOW（Bring Your Own Weights）+ 多模型 + 微调闭环」，并不仅仅是开源模型的托管服务，而是在帮助企业重新掌握 AI 主权。它既能承接最前沿开源模型的推理需求，也能帮助企业搭建自己的模型基础设施层。从产业链角度看：开源模型越强 → 企业对闭源 API 越谨慎 → 模型生态越碎片 → Fireworks 的价值就越高。Microsoft Foundry 与 Fireworks 的合作说明：即便是最大的闭源云平台，也仍然需要将部分开源推理能力外包给 Fireworks。

产品介绍

  • 定位：Fireworks AI 是面向企业生产环境的 AI 推理云，核心理念是把"训练好的开源模型变成企业生产级 AI 应用"。把 Meta 内部花了 5 年才做成的工程，压缩到 5 周甚至 5 天
  • 核心引擎 FireAttention + FireOptimizer：自研 CUDA 内核、模型分片、推测解码（speculative decoding）、语义缓存，号称比 vLLM 快 12x、比 GPT-4 标杆快 40x，单 GPU 可同时挂载上百个 LoRA adapter
  • 全栈推理 + 微调闭环：在同一平台支持模型选型、SFT/DPO/RFT 微调（含强化学习）、推理部署、模型评测（Eval Protocol），客户可以从"试 model"到"生产部署"端到端不出平台
  • Bring-Your-Own-Weights（BYOW）+ 多形态部署：serverless / on-demand / dedicated / enterprise（含 VPC 私有部署）；OpenAI 兼容 API，已通过 SOC2 / HIPAA / GDPR
  • 对开发者：百行配置可以从 OpenAI API 一键切换到开源模型，省钱（号称单位成本最高 8x 降幅）、不被锁定；对企业：可以"拥有自己的 AI"，模型权重、数据、微调过程全部留在客户侧

GTM

  • PLG + 开发者优先：从开源模型生态（Llama、DeepSeek、Kimi、Qwen 等）的 Day-0 launch partner 切入，吸引开发者自助接入，再向上扩展至企业合约
  • 生态分发杠杆：2026 年 3 月宣布与 Microsoft Foundry / Azure 的多年战略合作（公开预览），把 Fireworks 嵌入到 Azure 企业销售通道；同期与 NVIDIA、AMD 在硬件层深度绑定
  • Vertical Land-and-Expand：从单一推理 endpoint 切入后，通过 fine-tuning、Eval Protocol、RFT 等模块持续 upsell；Cursor、Notion、Shopify 等头部客户均从单点扩展到多场景
  • 目标客户：AI Native 高增长应用（Cursor、Perplexity、Genspark、Retell AI）+ 传统大企业 AI 化（Samsung、Uber、DoorDash、Shopify、Notion、Upwork、GitLab、Sourcegraph、Quora）

Traction

  • ARR：2025-05 $130M → 2025-07 $200M → 2025-10 $280M → 2026-02 $315M（+416% YoY，ChatForest 口径）
  • Token 吞吐：日处理 10-13 万亿 tokens（与 Google Gemini 同量级），峰值 180K requests/sec，单模型可达 1,000+ tokens/sec
  • 客户数：10,000+ 企业客户（较 Series B 翻 10x），数十万开发者；2025 年内客户数从 ~1,000 跃升到 10,000+
  • 标杆客户战果：
    • Notion：fine-tuning 后将延迟从 2 秒压到 350ms（约 4x 降幅），支撑 1 亿+ 用户的"vibe working" agentic workflow
    • Cursor：Composer 2 与 Fast Apply / Copilot++ 跑在 Fireworks 上，量化模型质量损失极小，延迟改善 ~3x
    • Upwork：Uma proposal 草拟功能延迟比 off-the-shelf 快 10x
    • Sourcegraph Cody：在 Fireworks 上做代码搜索与微调
  • 战略动作：2026-03 完成 Hathora 收购（覆盖 4 个云厂商、14 个 region 的实时编排层），实现全球低延迟部署
  • 本轮情况：Index Ventures 领投 @ $15B post money，NVIDIA 等战略方跟投

商业模式

  • 核心收入：按 Token 计费的推理 API + Dedicated GPU 容量（serverless + reserved 双线）；与 Together 的差异在于，Fireworks 可以靠性能和数据主权进行溢价。同样的 GPU，Fireworks 可以给出更高的性能，所有模型权重和数据都留在客户手中。Together 更接近 GPU 出租和通用 API 低价跑量的模式。
  • 追加销售：微调服务（SFT/DPO/RFT）、Eval Protocol、Multi-LoRA、Compound AI / Function Calling、企业 VPC 部署
  • 毛利结构：Sacra 认为，Fireworks AI 的推理定价已高于 Together AI 接近 breakeven 的水平，说明 Fireworks 在 Token 单位经济上具备更强的 take rate。同等算力条件下，FireAttention 带来的吞吐与速度优势，也能够直接转化为更高毛利。
  • 客户结构：偏 ICP 大客单价 + 长尾开发者订阅；141 名员工撑起 ~$300M+ ARR，人效极高（人均 ARR 接近 $2M）

竞对分析

Fireworks 的优势在于：

  • PyTorch 创始团队 + 内核级优化能力：CEO Lin Qiao 在 Meta 负责 PyTorch 达 7 年，团队也是 PyTorch 的核心维护者，能够从 CUDA 到分布式推理对整个技术栈进行深度改造；这是 Together.ai（学术派系）、Baseten（应用层为主）、Modal（Serverless Infra 为主）很难复制的优势
  • 同等算力的性能溢价 = 直接毛利：在 GPU 全行业紧缺、单卡价格高企的窗口期，FireAttention V4 / 推测解码 / 多 LoRA 服务让 Fireworks 在 H200/B200 上跑出更高吞吐，等价于"每张卡多赚 30-50% 收入"
  • 战略生态站位：唯一同时被 NVIDIA + AMD + Databricks + MongoDB + Microsoft Foundry 接纳的独立推理云；硬件与渠道两端拿满了重要合作
  • YTD 4x 增长 + 10x 客户增长：在 $300M+ ARR 体量上还能 YTD 4x。随着 Inference 需求激增，未来业务还有更多增长潜力
