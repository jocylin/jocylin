Executive View · PAGE 01

一句话结论

SpaceX 的核心不是火箭，而是把「进入太空」从一次性国家工程压缩成可复用、可排班、可规模化的运输服务；一旦运输成本下降，通信、数据、制造、居住和防务都会被重新定价。

  • Base case：Starlink 继续证明低轨通信现金流，Falcon 9 保持发射现金牛。
  • Upside case：Starship 把单位入轨成本再压低一个数量级，打开在轨制造、商业空间站、月球/火星物流。
  • Option case：xAI/SpaceX 结合让 AI 训练、自治系统和太空基础设施出现新耦合。

Investor Question · PAGE 02

投资人真正要问的问题

这个材料不是问 SpaceX 会不会发火箭，而是问：当低轨成为可运营基础设施之后，哪一层会捕获价值？

  • 运输层规模最大但资本开支重。
  • 通信层已经出现 Starlink 这种现金流曲线。
  • 应用层尚早，但一旦成本阈值被击穿，增长弹性最大。

原始观点

产业含义

这是高不确定但值得跟踪的 optionality：如果地面 data center 受制于电网，轨道能源与散热/维护的 tradeoff 会成为新前沿。

成本革命：从1-2万美金每公斤降到100美金每公斤

原始观点

产业含义

所有下游应用的投资判断，第一问都是：单位质量入轨成本下降后，商业模型是否跨过阈值？

原始观点

嘉宾加入SpaceX后首先负责飞龙号的内部结构，飞龙号是运送货物到国际太空站的飞船，太空人进入太空站第一个接触到的就是飞龙号内部，相当于做全世界最高科技的宜家橱柜，要求最轻还要承受几倍重力，很多部件都需要自己开发，一个橱柜的成本比美国中西部一栋房子还贵。嘉宾在飞龙号做得很好，SpaceX的惯例是你做得越好，给你的任务越多，所以一年后就把嘉宾调到猎鹰九号，负责猎鹰九号的制造扩张，因为马斯克给猎鹰九号定的目标是一年至少发射40次，当时全球一年发射才77次，SpaceX一年才发射1次，直接定40次的目标，需要扩大量产能力，嘉宾有量产经验，所以负责这个项目。

投资人解读

SpaceX 的激励逻辑很硬：能力被验证后，责任不是减少而是指数级增加。

产业含义

这解释了为什么高潜力员工能快速管多个 critical path，也解释了 burn-out 风险。

01:23:25 · PAGE 23

Mini Cooper团队为什么能帮SpaceX做量产

原始观点

SpaceX扩张猎鹰九号量产，找了Mini Cooper的团队来搭建生产体系，因为Mini Cooper是所有车企里SKU最多的，同一个车型可以有几十上百种不同配置，生产线能适应高SKU变化的需求。而早期猎鹰九号每次发射都会做改进，没有两只猎鹰九号完全一样，每次发射都会把迭代改进放到下一只火箭，所以需要高变化高量产的生产线，这正好是Mini Cooper团队擅长的，所以这个选择非常匹配SpaceX的需求。

投资人解读

Mini Cooper 的高 SKU 生产体系启发 Falcon 9：高变化、高频迭代也要可制造。

产业含义

核心洞察：火箭量产不是单一型号复制，而是在持续迭代中保持制造节拍。

马斯克的第一原理沟通：拿可乐罐要求火箭高压桶

原始观点

投资人解读

可乐罐类比不是说火箭等于饮料罐，而是逼团队从材料、压力、吞吐、成本的底层物理重新想。

产业含义

这是一种 brutal benchmarking：不要和行业平均比，要和物理极限与成熟制造业比。

猎鹰九号的两个核心里程碑

投资人解读

第一阶段是技术证明：能回收。第二阶段是运营证明：能稳定复用并规模发射。

产业含义

Value Chain Map · PAGE 41

产业链地图：上游苦活，中游运营，下游应用

上游是发射器、卫星、空间站和关键部件；中游是轨道运营、频谱、地面站、数据链路；下游才是互联网、国防、遥感、制造、科研、旅游、AI 计算等应用。

  • SpaceX 的强势在于把上游运输与下游 Starlink 现金流打通。
  • 创业公司若只做上游硬件，融资强度会极高；若依附 SpaceX 平台做应用，时点和平台依赖是核心风险。
  • 最优区域通常是「平台扩张后必须外包/生态化」的中游软件、运维、监测、安全、保险。
Investment Framework · PAGE 42

投资框架：五个可投问题

判断一个太空项目，不要先问故事大不大，先问它是否被 SpaceX 的成本曲线真实解锁。

  • 成本阈值：Starship/Falcon 9 成本下降后，单位经济是否成立？
  • 客户阈值：NASA/国防/运营商/企业客户是否已经愿意付费？
  • 平台阈值：依赖 SpaceX 是 leverage 还是 single-point risk？
  • 监管阈值：频谱、轨道、出口管制、发射许可是否可控？
  • 团队阈值：是否有 SpaceX/Tesla 级硬件交付经验？
Risk Register · PAGE 43

风险清单：别把文明叙事当成财务模型

SpaceX 的叙事很强，但风险也是真实的：Starship 进度、监管、事故、资本开支、卫星拥堵、地缘政治都会影响兑现。

  • 工程风险：Starship 完全复用尚需高频验证。
  • 财务风险：AI/太空数据中心极耗资本，收入兑现周期不明。
  • 监管风险：频谱、发射、轨道碎片、国家安全审查。
  • 竞争风险：中国航天、Blue Origin、Rocket Lab、欧洲/印度商业航天。
  • 外部性风险：天文观测、轨道垃圾、环境争议。
Final Thesis · PAGE 44

最终判断：SpaceX 是太空时代的平台公司

如果 Falcon 9 是 Model T，Starlink 是现金流，Starship 是平台升级，那么 SpaceX 的真正估值逻辑不是单一发射收入，而是它能否成为低轨经济的默认入口。

  • 短期看 Starlink 与 Falcon 9 的现金流和发射节奏。
  • 中期看 Starship 是否把成本曲线继续打穿。
  • 长期看 AI、在轨制造、商业空间站、月球/火星物流是否出现第二、第三条 Starlink。
