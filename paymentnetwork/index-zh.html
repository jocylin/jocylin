创始合作伙伴邀请 · 香港 · 2026

一个由成员共同搭建的中立支付联盟

Asia Payment Network 是一个在香港发起、准入制、面向稳定币与跨境支付基础设施的中立联盟。它服务的不是单一发行方或单一公链，而是一组正在亚洲搭建合规支付、结算与代币化通道的公司。

发起方IOSG Ventures
创始成员6–10 家 anchor
基地香港
01

为什么是现在

三股相互独立的变化，打开了一个 18 个月前还不存在的窗口：香港监管框架落地、稳定币进入持牌阶段、亚洲跨境支付重新寻找中立组织者。

监管

一个已经生效的监管闭环

香港《稳定币条例》已于 2025 年 8 月 1 日生效，HKMA 已将法币参考稳定币发行纳入持牌监管；Policy Statement 2.0 / LEAP 进一步把稳定币、代币化产品、应用场景与人才伙伴纳入同一政策框架。能走到队伍前列的，靠的是合规协调能力，而不只是规模。

市场

一个交易高峰

稳定币正在从交易所内部结算，走向商户收单、跨境 B2B、发卡、treasury 与 RWA 结算。问题也随之改变：市场不再只缺一个 issuer，而是缺一个能把持牌发行、PSP、卡组织、托管、合规工具和链上结算接起来的协作层。

结构

一个组织者真空

单一公司很难同时取得监管信任、商业中立性与跨境网络效应。Asia Payment Network 的机会不是做又一个钱包或支付公司，而是组织一张由成员共同定义规则、共同贡献流量、共同分享标准的商业网络。

机会所在

香港已经给出了监管入口，市场已经给出了稳定币支付的商业需求，但中间缺一层可信的 multilateral coordination。这正是这个 network 要占据的位置。

02

这个 network 做什么

四项功能，每一项都让成员从第一个季度起就能用上——它不是一场会议，也不是一个没有通道的标准机构。

Function 01

组织

由创始成员组成、每季度召开的闭门 working group，外加一年一度的香港峰会。一个真正让搭建亚洲支付通道的人共同制定议程的房间。

Function 02

互联

成员之间互相打通——发卡对接跨境通道，代币化资产经由稳定币通道结算，合规工具在 PSP 之间共享。Network 充当撮合方与信任层。

Function 03

代表

在与香港监管机构、政策部门和行业基础设施方的对话中，提供一个统一的集体声音。就框架、用例和风险控制进行沟通，作为一个群体，远比一家家单打独斗更便宜、也更可信。

Function 04

研究

一份季度亚洲支付研究报告、稳定币支付用例追踪，以及一份持续维护的成员名录——共享的市场情报，抬高每一位参与者的站位。

03

完整支付价值链，装进一个 network

创始合作伙伴覆盖整条价值链——这样联盟能打通一条完整的支付流，而不是其中某一段。

Layer 01资产

持牌稳定币与代币化货币的发行方，其价值在网络中流转。

Layer 02链与结算

chain-agnostic 的结算通道。网络不偏向任何单一公链或发行方。

Layer 03出入金、托管与 PSP

联盟的主力层：法币加密出入金通道、托管，以及负责资金进出的支付服务商。

Layer 04发卡

BIN sponsor 与发卡方，把链上余额连到日常的刷卡消费。

Layer 05Neobank 与收益

面向消费者的 neobank，以及让余额产生收益的 yield 层。

Layer 06合规

从一开始就内置筛查与监控，让合规成为共享标准，而非事后补课。

创始合作伙伴在以上各层中择优准入。具体公司名单在联盟准入流程中，向潜在成员私下披露。

04

设计原则

联盟如何在结构上保持中立、并值得加入。以下是创始阶段的设计承诺——与创始成员共同打磨，而非既定条款。

P1

与贡献挂钩的经济结构

联盟的设计目标是：在共享结算层产生的经济价值，按对 network 的贡献进行分配，而不是被单一发行方独占。其意图是成员之间的结构性利益对齐；具体机制与创始成员共同制定。

P2

非歧视性定价

成员在定价上一视同仁，不论规模大小，沿用成熟清算机构的合作社模型。没有成员能仅凭体量大就买到优势。

P3

辖区中立的治理

董事会的设计确保没有任何单一辖区能够主导。中立性本身就是资产；联盟刻意不被搭建成任何一方阵营的工具。

P4

合规优先、chain-agnostic

从一开始就内置合规姿态与准入控制，且不绑定任何单一公链或发行方。真实的资产与真实的通道，而不是一堆 logo 的集合。

05

事实底座

06

创始合作伙伴得到什么、付出什么

作为创始合作伙伴，你将

  • 参与书写治理规则——董事会结构、准入规则与经济设计由创始成员共同确定，而非自上而下下发。
  • 坐在季度 working group 中，并参与塑造年度峰会议程。
  • 获得成员间互联——与其他 anchor 的暖性引荐与技术对接。
  • 作为一个被认可的群体的一员，加入香港的集体监管对话。
  • 在 network 的研究与对外形象中获得创始成员身份的认可。

作为回报，我们希望伙伴

  • 指派一位具名的资深代表进入 working group。
  • 在有商业意义之处，就互联与其他成员真诚合作。
  • 遵守联盟的合规与准入标准。
  • 在头两个季度协助打磨创始章程。
关于发起方

Asia Payment Network 由 IOSG Ventures 发起。IOSG 是一家自 2017 年起活跃于数字资产与支付基础设施领域的投资机构。

IOSG 的角色被刻意限定：组织、研究，以及投资关键公司的股权。联盟由成员塑造，IOSG 自身不持牌、也不经营任何支付业务。目标是让这个 network 的生命力超越、并成长得超过任何单一组织者。

创始成员的规模，是刻意做小的。

我们把第一批成员控制在 6 到 10 家 anchor，以保证治理可运作、每一个创始声音都有分量。如果你的公司在亚洲、或面向亚洲搭建稳定币支付、结算或代币化通道，我们想和你聊聊。
