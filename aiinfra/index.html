Part I

五代基础设施：从运力到智力

人类文明的底层基础设施经历了五次跃迁。每一次跃迁都把一种稀缺资源变成通用服务，从而释放出新一轮的大规模创新。

代际基础设施起点标志本质
第一代运力铁路 → 公路 → 海运 → 航空物质的移动
第二代电力1913 福特电驱流水线能量的通用化
第三代通信~2000 洲际光纤网络信息的移动
第四代算力2006 AWS 发布计算的通用化
第五代智力2021 OpenAI 开放 API智能的通用化

今天大模型公司的激烈竞争，本质上是智力基础设施的建设期。几年后行业整合完成，卖 Token 提供通用智能服务，就会像卖电、卖算力一样——摩尔定律会把智力的边际成本压到接近零。

每一代基础设施的商业终局都是 public utility：标准化接入、充分竞争、利润率收敛。

这不是 AI 的终局，这只是 AI 的开局。
基础设施成熟后，真正的大创新才刚刚开始。

历史反复证明：杀手级应用从来不是基础设施提供商做出来的——铁路公司没做出沃尔玛，电力公司没做出福特，AWS 没做出 Uber。卖 Token 的公司大概率也不会是 AI 时代最大的赢家。

Part II

耗散结构：把框架往上拉一层

Ilya Prigogine 的耗散结构理论提供了一个更深层的解释框架：

复杂系统通过消耗更多能量来维持更高层次的秩序。

每一代基础设施本质上都是一个新的耗散层级——把低阶能量转化为高阶秩序：

铁路
煤的化学能 → 运力
电网
一次能源 → 通用能量形式
互联网
电力 → 信息流动
云计算
电力 → 计算能力
大模型
算力 → 智力

每一层都消耗更多能量，也产生更高阶的秩序。这不是浪费，这是复杂系统演化的基本规律。

效率提升当然会发生——汽车越来越省油，芯片越来越省电，模型推理成本在指数下降。但每一轮效率红利都会被新一层需求的爆炸吃掉。

"省电"从来不是文明演化的方向。
"找到更多电"才是。
Part III

戴森球：不是科幻，是热力学必然

1960年，物理学家 Freeman Dyson 提出：一个足够先进的文明，最终会把整颗恒星包起来，截获它全部的能量输出。

太阳每秒释放 3.8×10²⁶ 瓦的能量，地球只接收到其中的二十亿分之一。剩下的全浪费了。

文明级别能力人类现状
I 型利用整个行星的全部能量我们约在 0.7，还没到 I 型
II 型利用整颗恒星的全部能量这就是戴森球
III 型利用整个星系的能量纯理论

从耗散结构的逻辑推：只要文明的能量需求持续指数增长，向恒星级能量获取迈进就不是选择题，是必答题。

AI 算力的爆炸式增长正在加速这个进程。训练一个前沿大模型的耗电量已经相当于一个小城市一年的用电。这条曲线外推下去，地面能源的天花板几十年内就会撞到。

热力学第二定律不允许文明在地面停下来。
Part IV

太空算力：戴森球的 0.01 版

太空算力和太空制造是绕不过去的方向，且长期必然成功。逻辑只有三步：

  1. 地面能量有上限。地球截获的太阳能是固定的，化石能源在耗尽，核能有政治和物理约束。AI 算力需求如果继续指数增长，地面供能几十年内就会撞墙。
  2. 太空没有这些约束。无限太阳能、真空散热效率高（算力的物理瓶颈其实是散热不是供电）、零重力环境对某些制造工艺有天然优势（晶体生长、光纤拉制）。
  3. 经济性正在跨过临界点。SpaceX 把发射成本从 $50,000/kg 压到 Starship 目标的 <$100/kg。太空基建正从国家工程变成商业可行。

Musk 的布局：一条线串起来

🚀 SpaceX
发射成本降100倍，太空准入门槛从国家级降到商业级
🛰️ Starlink
太空通信网络，未来太空算力的数据回传通道
☀️ Tesla Energy
地面太阳能采集 + Megapack 储能，能源端布局
🧠 xAI
超级算力中心，对电力需求已到自建发电的程度

降低太空准入成本 → 构建太空通信网 → 部署太空太阳能采集 → 为地面/太空算力供电。这就是戴森球的第一步。

太空太阳能发电站——在轨道上铺太阳能板，用微波传回地球——中国、日本、ESA 都在认真研究。这不是科幻，是正在推进的工程项目。

Part V

核能注定是小众市场

从耗散结构的视角，核能有一个致命的结构性缺陷：

核能是从地面有限的铀/钍矿中提取能量，本质上还是在"地球存量"里打转。
而太阳能是直接接入恒星的"增量"。

太阳每秒的能量输出，比人类挖出的所有铀全部裂变还多不知道多少倍。核能的宿命 = 过渡方案，就像煤炭之于石油——不是不能用，而是在更大尺度的能量获取方式面前，它天然是小众的。

核能的甜蜜点在"阳光不够的角落"：高纬度地区、军事潜艇、深空探测。这些都是太阳光照不到的特殊场景。一旦太空太阳能采集成熟，连这些角落都会被挤压。

文明的能量来源最终会收敛到离恒星最近的路径。
核能离恒星太远了——它是拆原子，不是接恒星。
Part VI

投资启示：跟着能量流向投

🏭
模型层是 utility 生意
激烈竞争 → 行业整合 → 利润率压缩。现在 all-in 模型层的资本，赌的是建设期超额利润，但终局是 utility 级回报。
🚀
应用层的 alpha 还没出现
每一代基础设施成熟后，最大赢家都在应用层。现在太早，但方向确定。最大的 AI 公司可能还没有被创立。
🛰️
太空基建是 30-50 年的确定性方向
发射成本下降 + 算力需求指数增长，会把太空算力从科幻推向商业现实。
⚛️
核能是过渡性配置
适合当前能源缺口，但长期会被太阳能（地面+太空）取代。配置可以，重仓要谨慎。
⚡
跟着能量流向投
耗散结构告诉我们：资本最终会流向能更高效获取和消耗能量的方向。这是比任何行业分析都更底层的投资逻辑。
推导链
五代基础设施 → 耗散结构 → 能量指数增长 → 戴森球必然性 → 太空算力/制造 → 核能小众化

这条链上的每一环都是热力学推出来的，不是想象出来的。
